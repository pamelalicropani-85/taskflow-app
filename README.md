# TaskFlow App

TaskFlow es una aplicación móvil de gestión de tareas, desarrollada con [Expo](https://expo.dev) y React Native.

Este repositorio corresponde al **Checkpoint 1: Estructura Base**, cuyo objetivo es sentar las bases del proyecto: inicializar la app, organizar las carpetas del código fuente y armar una primera pantalla de bienvenida usando `View`, `Text` y `StyleSheet`.


### Requisitos previos

- [Node.js](https://nodejs.org/) (v18 o superior)
- npm
- [Expo Go](https://expo.dev/go) instalado en tu celular (opcional, para probar en un dispositivo físico) o un emulador de iOS/Android



## Próximos pasos

Esta es la primera pre-entrega del proyecto final. Los siguientes checkpoints irán agregando funcionalidades como navegación entre pantallas, gestión de tareas (crear, editar, eliminar) y persistencia de datos.
